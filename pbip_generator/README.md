# PBIP Generator

```bash
python generate_city.py --city chicago --pbip-only
python -m pbip_generator.build_pbip
```

Output:

```text
generated_reports/chicago/
    ChicagoPulse.pbip
    ChicagoPulse.Report/
    ChicagoPulse.SemanticModel/
    data/*.csv
    dax/measures.txt
    semantic_model_metadata.json
```

Open `ChicagoPulse.pbip` in **Power BI Desktop** — three pages ship with programmatic visuals:

| Page | Visuals |
|------|---------|
| Live City Pulse | KPI card row (stress, CTA alerts, anomaly count) + anomaly table |
| Transit & Mobility | Clustered bar — alert category vs count |
| Weather Impact | Precip bar chart + temperature line chart |

Visual JSON is generated by `pbip_generator/visuals.py` (see RuiRomano/pbip-demo patterns).

README PNG previews: `python tools/capture_readme_screenshots.py --city chicago`

Theme: charcoal `#0F172A`, slate panels `#1E293B`, electric cyan `#22D3EE`.
